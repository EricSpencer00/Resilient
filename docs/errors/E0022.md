# E0022 — Duplicate named argument
{: .no_toc }

A call supplies the same named argument label more than once. Each
parameter can receive at most one named value.
{: .fs-5 .fw-300 }

---

## What triggers it

The parser reports E0022 when a call repeats a named label in its argument
list, even if the two values have different expressions.

## Minimal example

~~~resilient
fn configure(int width, int height) {
    return width + height;
}

let area = configure(width: 10, width: 20);
~~~

The rich diagnostic is:

~~~text
3:39: [E0022] Duplicate named argument width in call
~~~

## Fix

Pass each named argument once. Remove the duplicate or use the correct
parameter label for the second value:

~~~resilient
let area = configure(width: 10, height: 20);
~~~

## Source

Emitted by the parser's named-argument validation in
resilient/src/lib.rs. The [E0022] code is shown when
RESILIENT_RICH_DIAG=1; the default diagnostic text remains unchanged.
