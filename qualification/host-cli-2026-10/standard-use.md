# Four preparation profiles

The evidence here supports the same narrow host certificate/replay operation in
four possible project contexts. This table maps preparation inputs; it does not
reproduce the standards or claim objective satisfaction. Exact editions,
objectives and classification require the consuming project's licensed basis.

| Profile | Concrete preparation supplied | Still required before project acceptance |
| --- | --- | --- |
| ISO 26262 | Identified tool use/baseline, operational requirements, negative and positive replay cases, restrictions and revalidation triggers. | Item and ASIL context, tool failure-impact/detection rationale and derived TCL, qualification-method selection, safety responsibilities and confirmation/assessment records. |
| DO-178C / DO-330 | Versioned executable/environment, tool operational requirements, requirements-based actual results, configuration and problem-report inventory. | Applicant's software level and agreed credit, tool criteria/TQL, qualification plan/results review, certification liaison and acceptance. Formal-methods credit additionally needs accepted formalization/translation argument and applicable DO-333 objectives. |
| IEC 62304 | Intended tool operation, versioned validation observations, failure cases, limitations and change triggers. | Manufacturer's intended-use validation under its QMS, software class/lifecycle scope, ISO 14971 hazard/risk-control links, residual-risk approval and maintenance responsibility. |
| IEC 61508 | Identified support-tool operation, failure observations, controlled baseline, tool-use validation inputs and restrictions. | Support-tool classification/failure impact, target SIL/methods combination, lifecycle plan, competence/independence and assessment records. |

No compiler test substitutes for target integration, structural coverage,
requirements correctness or project risk acceptance. The combined intake lists
all four profiles so missing project-specific controls remain visible; a customer
must tailor or separate them for materially different uses and baselines.
